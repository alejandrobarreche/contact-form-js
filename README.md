# Contact form — HTML, CSS and vanilla JavaScript

Class exercise for *Informática II* (UAX, 2025): a contact form with client-side validation written in plain HTML, CSS and JavaScript, no frameworks.

`index.html` + `script.js` + `styles.css` is the delivered version. The other files (`index2.html`, `index3.html`, `indexx.html`, `scriptt.js`, `styless.css`) are earlier iterations kept for reference.

## Run

Open `index.html` in a browser. Empty fields are highlighted on submit and the form is not sent.
